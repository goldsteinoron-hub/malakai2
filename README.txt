# מלאקיי — אתר לאייפון

## מה יש כאן
- ממשק מותאם לאייפון ואפשרות Add to Home Screen.
- כפתור כחול: בקשת הרשאת תנועה והפעלת דיבור בעברית.
- כפתור אפור: מעבר בין הפנים לזיכרונות.
- "שכח הכול": מנקה את היסטוריית השיחה אבל משאיר את הזיכרונות השמורים.
- שיחות AI דרך שרת מאובטח; מפתח ה-API נשמר בצד השרת ולא בתוך HTML.

## פרסום
הקובץ מוכן לפריסה ב-Cloudflare Pages עם Pages Function.
1. העלה את כל התיקייה `malakai_site` למאגר GitHub פרטי.
2. ב-Cloudflare Pages צור פרויקט שמחובר למאגר. Build command: ריק. Build output directory: `/` (שורש הפרויקט).
3. ב-Cloudflare Pages > Settings > Variables and Secrets הוסף Secret בשם `OPENAI_API_KEY`.
4. אופציונלי: הוסף משתנה `OPENAI_MODEL` עם מודל API זמין בחשבון.
5. פרוס. האתר יהיה זמין בכתובת HTTPS של Cloudflare Pages.
6. פתח את הכתובת ב-Safari > Share > Add to Home Screen.

## חשוב
- אין אפשרות לפרסם לאינטרנט מתוך הצ'אט בלי חשבון אירוח והרשאה של בעל החשבון.
- מפתח API וחיובים/הרשאות צריכים להיות מוגדרים על ידי מבוגר אחראי. אל תשלח את המפתח בצ'אט ואל תכניס אותו לקובץ HTML.
- זיהוי תנועה ב-iPhone דורש HTTPS והרשאה. זיהוי דיבור נתמך לפי הדפדפן; אם אינו זמין, אפשר להקליד.
- הזיכרונות נשמרים ב-localStorage של הדפדפן במכשיר הזה. ניקוי נתוני Safari עלול למחוק אותם.
